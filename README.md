# Login Form Task

## Project Description
A simple Java login form built using AWT.

## Features
- Validates that username and password are not empty.
- Checks the username, password, and selected role.
- Displays an error message for invalid credentials.
- Disables the Login button after three failed attempts.
- Displays a welcome page after successful login.

Compile the program:
